# Экосистема коммерческого блока Ростелекома (Ростовская область)

Аналитическая геоплатформа для коммерческого блока ПАО «Ростелеком». Система объединяет геопространственный анализ клиентской базы, мониторинг инвестиционных проектов региона, оценку потенциала территорий («белые пятна») и автоматизированный калькулятор B2B-сделок.

Платформа развёрнута на данных по Ростовской области (188 000+ субъектов МСП, 4 600+ верифицированных геокодированных точек организаций, реестр инвестиционных проектов DonInvest и закупки ЕИС).

---

## Возможности системы

### 1. Радар присутствия и потенциала территорий
- **Интерактивная карта 2ГИС + Deck.gl**: тепловая карта и полигоны 55 муниципальных районов и городских округов, точечный слой компаний.
- **Динамический расчет потенциала**: настраиваемая взвешенная формула (доход компаний, динамика год к году, недоохват РТК). Мгновенный пересчет в браузере при движении ползунков.
- **Выявление «белых пятен»**: автоматическое выделение районов с низким текущим проникновением услуг РТК (менее 75% от среднего) и высоким платежеспособным спросом (верхняя треть региона).
- **Карточка организации**: ИНН, ОГРН, КПП, статус ЕГРЮЛ, надежность адреса (ФИАС, уровень точности DaData), динамика выручки, филиальная сеть и список рекомендованных телеком-продуктов по ОКВЭД.
- **Экспорт лидов**: выгрузка сформированных списков в CSV и готовые форматы для amoCRM и Bitrix24.

### 2. Инвестиционный навигатор
- **Мониторинг инвестпроектов**: реестр и интерактивная карта проектов Ростовской области (промышленность, АПК, логистика, инфраструктура, туризм).
- **Классификация потребностей**: сопоставление проектов со спецификой телеком-решений (АСУ ТП / промышленный IoT, ИТ-инфраструктура, системы безопасности и видеонаблюдения).
- **Связка с юрлицами**: сопоставление инициаторов с реестром МСП, оценка финансовой устойчивости и планируемых инвестиций.

### 3. Калькулятор B2B-сделок
- **Моделирование контрактов**: расчет стоимости и маржинальности комплексных подключений (ШПД, VPN, видеонаблюдение, Виртуальная АТС, облачные сервисы, телеметрия).
- **Коэффициенты условий**: учет сложности трассы, удаленности от узла связи, рассрочки оборудования и проектных рисков.
- **Быстрый переход**: запуск расчета прямо из карточки компании или инвестпроекта с автозаполнением параметров.

### 4. Авторизация и безопасность (2FA)
- **Двухфакторный вход**: пароль + подтверждение одноразовым 6-значным кодом на email.
- **Гостевой доступ**: отдельный безопасный режим быстрого входа для жюри и экспертов без предварительной регистрации.
- **Интерактивный тур**: встроенные обучающие подсказки на каждой вкладке системы.

## Быстрый запуск

### Вариант 1: Запуск на Windows через start.bat (рекомендуемый)

Требования:
- **Windows 10 / 11**
- **Node.js 20+** (https://nodejs.org)
- **Python 3.10–3.13 x64** (https://python.org)

Скрипт полностью автоматизирован: проверяет окружение, создает изолированный .venv, устанавливает библиотеки, настраивает фронтенд и запускает API и веб-интерфейс.

1. Запустите в корне репозитория:
   `cmd
   start.bat
   `
2. При первом старте скрипт автоматически создаст .env из шаблона .env.example (с преднастроенным доступом к демонстрационной базе на сервере и ключом карты 2ГИС).
3. После запуска откроются окна API и сайта, а в браузере откроется http://localhost:5173.
4. Для входа выберите **«Войти гостем»** (для жюри) или зарегистрируйтесь. В режиме разработки код подтверждения также дублируется в консоль окна API.

Для остановки достаточно закрыть окна API и сайта.

---

### Вариант 2: Локальный Docker Compose

Требования: **Docker Desktop** c поддержкой Docker Compose.

1. Создайте .env (или скопируйте .env.example):
   `ash
   cp .env.example .env
   `
2. Поднимите стек (PostGIS + FastAPI + React/Vite):
   `ash
   docker compose up -d
   `
3. Сайт откроется на http://localhost:5173, API — на http://localhost:8000.

## Архитектура и стек технологий

`	ext
├── assets/brand/      Шрифты Rostelecom Basis, фирменные токены и SVG-логотипы
├── backend/
│   ├── app/           FastAPI, авторизация, маршруты API (radar, invest, gov, calc)
│   ├── etl/           Скрипты обработки данных ФНС, МСП, DaData, 2ГИС, ЕИС
│   ├── load/          Загрузчики данных в PostgreSQL / PostGIS
│   └── tests/         Автотесты API и CRM-экспорта
├── deploy/            Конфигурация Nginx, скрипты инициализации БД
├── frontend/
│   ├── src/           React 18 + TypeScript + Vite
│   │   ├── auth/      2FA авторизация, гостевой вход, сессии
│   │   ├── radar/     Карта присутствия, фильтры, карточки, расчет потенциала
│   │   ├── invest/    Инвестиционный навигатор и витрина проектов
│   │   ├── calc/      Калькулятор B2B-сделок
│   │   └── tour/      Интерактивный тур и контекстные подсказки
├── prototype/         Ранний статический прототип для автономных демонстраций
└── scripts/           Вспомогательные утилиты сборки демо-наборов
`

- **Frontend**: React 18, TypeScript, Vite, TanStack Query, Deck.gl, 2GIS MapGL.
- **Backend**: FastAPI, SQLAlchemy, Uvicorn, psycopg 3.
- **База данных**: PostgreSQL 16 + PostGIS 3.4.
